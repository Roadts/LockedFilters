These examples were created solely to help people build things with the APIs. For example, we have website examples, CLI examples, Discord and Telegram bots just about everything as an example. It shows how to use it in 2 ways (Using the service itself or the NPM // PY // NET package) and includes comments explaining every part along the way.

  
**Website Example** ~ This example website keeps the backend safe and secure for link checking. It uses [Vanilla HTML](https://plainvanillaweb.com/index.html), CSS, JavaScript, and a service such as Cloudflare Workers to run the backend API. This example still isn't the safest, AKA the preferred method. Much of this logic is client-side and can still be changed. I recommend a frontend-based language that has SOP capabilities for better control over the client. A great example already exists in some of our examples.
